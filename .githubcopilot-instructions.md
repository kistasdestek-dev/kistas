# AI Assistant Guidelines for Next.js Architecture

## Stack Constraints
- Next.js (App Router), TypeScript (Strict), Tailwind CSS.
- Default to React Server Components (RSC). Use 'use client' only when hooks/interactivity are required.

## Token Conservation & Output Rules
- NEVER rewrite entire files or unchanged code blocks.
- Always preserve existing structure using comments: `// ... existing imports ...`, `// ... existing code ...`.
- Return only targeted diffs, modified functions, or specific component slices.
- Omit conversational preambles ("Here is the solution...") and postscripts. Output production-ready code directly.
